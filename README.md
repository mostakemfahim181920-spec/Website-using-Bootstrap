# Responsive Business Website Template

> A clean, modern, and fully responsive multi-section website built using **HTML5**, **CSS3**, and **Bootstrap 5**.

---

## 📖 Project Overview

This project is a single-page responsive website template designed for modern business, agency, or portfolio landing pages. It features a sticky navigation bar with smooth scrolling, a dynamic full-width hero carousel slider, service cards, team profile cards, a working contact form layout, and a structured footer. 

Key features include:
* **Fully Responsive:** Seamlessly adapts across mobile, tablet, and desktop screen sizes using modern CSS and Bootstrap's flexbox grid system.
* **Smooth Internal Navigation:** Quick Jump links targeting page sections (`#home`, `#about`, `#services`, `#team`, `#contact`).
* **Zero Heavy Dependencies:** Light on external libraries, utilizing standard HTML5 semantics, custom CSS, and vanilla Bootstrap 5 bundles.
